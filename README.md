# 地铁报站模拟语音包

暂定名称，最终名称后续再确定。

一个面向地铁爱好者的微信小程序，提供按城市、线路、广播类型和版本浏览的语音包。首版先做北京，后续逐步增加上海、广州、深圳等城市。

## 首版方向

- 主流程：北京 → 线路 → 语音包 → 音频列表 → 播放。
- 收录车内报站、站台广播和历史版本，不要求音频必须是最新版本。
- 资源应声音清晰、内容对应、范围明确；部分收录就如实标明，不把目录齐全等同于音频齐全。
- 不做社交、用户投稿或录音上传。
- 广告解锁语音包、会员听全部是计划中的变现方式，接入资格与规则仍待核实。
- 线路图、方向和区间联动作为后续增强。

## 当前进度

已创建项目目录、首版产品范围和北京音源目录索引。目前处于资源盘点阶段，尚未创建小程序运行代码、下载音频或接入广告和支付。
